# 本周学习总结（Web前端岗位学习计划 Day1-Day5）

## 本周学到的三个新命令

### 1. `git clone <仓库地址>`
- **作用**：将远程 GitHub 仓库完整地复制到本地电脑。
- **示例**：`git clone https://github.com/hahameiry/fe-standby-training.git`
- **应用场景**：开始一个新任务时，先将公司或自己的代码仓库下载到本地进行开发。

### 2. `git add .`
- **作用**：将当前目录下所有修改过的文件添加到 Git 的“暂存区”，准备提交。
- **示例**：`git add .`
- **应用场景**：完成一天的学习任务后，用此命令把所有改动（HTML、CSS、截图等）标记为待提交。

### 3. `git commit -m "提交说明"`
- **作用**：将暂存区的改动生成一个本地版本快照，并附上说明文字。
- **示例**：`git commit -m "完成Day4静态页面，适配移动端"`
- **应用场景**：每次完成一个阶段性任务后，用清晰的说明保存进度，方便后续查看或回退。

## 额外掌握的辅助命令
- `git status`：查看当前文件状态（哪些被修改、哪些已暂存）。
- `git push`：将本地的提交推送到 GitHub 远程仓库。
