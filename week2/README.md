# 第二周周记

## 本周学习内容

### 第六天 —— 数组方法入门
学习了 JavaScript 数组的三个核心方法：`map`、`filter`、`find`。
用一个包含姓名和年龄的对象数组做练习，分别实现了提取所有人名字、筛选年龄大于25的人、查找指定姓名的人。

### 第七天 —— 模块化拆分
在第六天的基础上，将数组方法封装成独立的工具函数模块 `utils.js`，
通过 ES Module 的 `export` / `import` 语法在 `main.js` 中调用，
初步体验了模块化开发的思路。

### 第八天 —— 笔记整理
对前几天的知识点进行了梳理和记录，整理成文档备查。

### 第九天 —— Vue 父子组件通信
学习 Vue 2 的父子组件通信：子组件通过 `$emit` 触发自定义事件，
父组件通过 `@add` 监听并累加总数，实现了三个子计数器共同驱动父组件总数的效果。


## 本周解决的 Bug

**问题：HTML 文件引入 JS 模块后控制台报中文乱码**

**现象：**
第七天把 `array-methods.js` 拆分成 `utils.js` + `main.js` 并改用 `type="module"` 引入后，
浏览器控制台输出的中文字符（如"所有人的名字："）全部显示为乱码。

**原因：**
JS 文件保存时编码为 GBK，而浏览器在处理 ES Module 时默认以 UTF-8 解析，
两种编码不一致导致中文字符无法正确渲染。

**解决方法：**
在编辑器（VS Code）右下角将文件编码从 GBK 切换为 UTF-8 并重新保存，
同时确认 HTML 文件头部已声明 `<meta charset="UTF-8">`，问题消失。

**收获：**
以后新建 JS / HTML 文件第一步就确认编码为 UTF-8，避免同样的问题再次出现。
